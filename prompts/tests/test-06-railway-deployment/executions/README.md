# Execuções — T06

Cada integrante deve criar uma pasta própria:

```text
executions/<identificador>/
├── request.json
├── response.json
├── output.md
├── usage.json
├── cost.md
├── evaluation.md
└── screenshots/
```

Não sobrescreva uma execução. Se o modelo, prompt, configuração ou branch mudar, use novo `run_id`.
