# Variação T01 — baseline

Não adicione few-shot, chain-of-thought, instrução de análise em etapas ou contexto externo. Produza a solução usando apenas o system prompt, a tarefa canônica, a stack, o contexto mínimo e o contrato de saída fornecidos nesta chamada. Trate as lacunas do contexto mínimo como lacunas reais.
