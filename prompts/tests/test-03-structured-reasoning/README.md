# T03 — Raciocínio estruturado

## Objetivo

Avaliar se uma sequência explícita de análise, decisão e implementação reduz omissões nos requisitos sem exigir a exposição de uma cadeia de pensamento privada.

## Variável do teste

Os mesmos dados do T01, acrescidos de instruções para produzir um resumo verificável de requisitos, decisões, validações e lacunas antes dos artefatos.

## Execução

1. Abra uma conversa nova ou faça uma chamada independente.
2. Envie o conteúdo integral de `prompt/assembled-prompt.md`.
3. Preserve a instrução de análise estruturada e compare o tamanho/qualidade da saída.
4. Salve request, resposta, tokens, custo e avaliação individual.

## Pergunta de comparação

A análise em etapas melhora a cobertura dos fluxos HPET04/HPET04a e a identificação de lacunas sem gerar texto desnecessário ou decisões não suportadas?
