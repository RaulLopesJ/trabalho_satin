# Variação T03 — raciocínio estruturado

Aplique uma estratégia de análise em etapas antes de produzir os artefatos. Apresente somente um resumo verificável, não uma cadeia de pensamento privada.

## Etapas obrigatórias do resumo

1. Inventarie os requisitos explicitamente disponíveis.
2. Relacione cada requisito ao fluxo HPET04 ou HPET04a.
3. Separe fatos, inferências técnicas e lacunas.
4. Defina as decisões mínimas de dados, API, interface e validação.
5. Verifique cada fluxo alternativo contra a solução proposta.
6. Liste os riscos de implementar algo que não esteja especificado.
7. Só depois produza os artefatos da vertical slice.

Use títulos `ANÁLISE`, `DECISÕES`, `IMPLEMENTAÇÃO` e `VALIDAÇÃO` para tornar o resultado auditável. Não invente uma regra apenas porque uma etapa do processo parece incompleta.
