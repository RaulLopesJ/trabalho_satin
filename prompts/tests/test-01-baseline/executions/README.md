# Execuções — T01

Crie uma subpasta por execução, por exemplo `integrante-01-20260819` ou `integrante-02-20260819-retry`. Não sobrescreva uma execução anterior.

Cada execução deve conter:

```text
request.json
response.json
output.md
usage.json
cost.md
evaluation.md
screenshots/
```

Use os modelos em `../../../../shared/templates/`. O request não pode conter API key. Uma resposta com erro deve ser preservada e identificada como falha; não substitua tokens ausentes por zero.
