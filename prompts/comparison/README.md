# Comparação dos cinco testes

A comparação deve usar chamadas válidas e preservar a distinção entre dados quantitativos e avaliação qualitativa.

## Comparações primárias

- T01 × T02: efeito dos exemplos few-shot com o mesmo contexto mínimo.
- T01 × T03: efeito do raciocínio estruturado com o mesmo contexto mínimo.
- T04 × T05: efeito do contexto completo versus contexto curado.

## Evidência mínima

Para cada chamada, preencher tokens de entrada/saída, preços, custo, status, modelo/API ID, prompt version, run ID e link/arquivo da evidência. Uma linha por chamada é necessária; não consolide retries sem identificá-los.

## Interpretação

Não declare que uma abordagem é melhor só porque produziu mais texto. Considere cobertura dos requisitos, fidelidade às fontes, necessidade de correção, capacidade de build e custo. Se os parâmetros ou contextos divergirem, marque a comparação como inconclusiva.
